struct sizing, using the 2 rules:
1. Each element must be padded so that its starting address is a multiple of its size
2. the total size of the struct must be a multiple of the largest data type in the struct
So s -> 1 + pad(3) + 4 = 8 bytes
str -> 8 bytes + /0 at the end of it


SOl.
a -> 4 * 10 = 40 bytes
p -> 8 (pointer always 8 bytes in a 64 bit machine)
a/p -> 10 (40/4)
s -> 8
str -> 9 (including the null terminator)
"hardware" -> 8 (no terminator)
a + 0 -> 8 (decays to int*)
&a -> 8 (address in 64 bit machine)
*&a -> 40 dereference will give the entire array block size
